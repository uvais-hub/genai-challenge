
# GenAI Study Project

This repository is a personal study project for learning Generative AI (GenAI) and related automation tools. It is organized into separate directories for different learning tracks:

## Project Structure

- **python-beginner/**: Contains Python basics and introductory scripts for learning core Python concepts.
- **rpa-with-python/**: Focuses on Robotic Process Automation (RPA) using PyAutoGUI and other automation libraries.
- **playright-for-begineers/**: Includes Playwright and Selenium scripts for browser automation and testing.

Each directory is dedicated to a specific topic to help you learn and experiment with GenAI and automation tools in Python.


## Directory Details

- **python-beginner/**
  - `datetimeoperations.py`: Practice with Python's datetime module.
  - `my-first.py`: First steps in Python scripting.
  - `python-basics.ipynb`: Jupyter notebook for Python basics.
  - `sample.txt`: Sample data for exercises.

- **rpa-with-python/**
  - `find-screen-coordinates.py`: Find screen coordinates using PyAutoGUI.
  - `keep-me-awake.py`: Prevent system sleep with automation.
  - `practice-py-autogui.py`: Practice scripts for PyAutoGUI.

- **playright-for-begineers/**
  - `playwright_key_functions.py`: Key Playwright automation functions.
  - `Seleinum-begineers.py`: Selenium automation examples.


## Getting Started

1. Clone the repository:
  ```zsh
  git clone https://github.com/uvais-hub/genai-challenge.git
  ```
2. Navigate to any directory and run the scripts using Python 3:
  ```zsh
  cd playright-for-begineers
  python3 Seleinum-begineers.py
  ```

## Requirements

- Python 3.x
- Recommended: Install required packages using pip:
  ```zsh
  pip install selenium playwright pyautogui
  ```
