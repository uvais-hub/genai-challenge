# RPA with Python

This folder contains scripts for Robotic Process Automation (RPA) using Python and PyAutoGUI.

- `find-screen-coordinates.py`: Find screen coordinates using PyAutoGUI.
- `keep-me-awake.py`: Prevent system sleep with automation.
- `practice-py-autogui.py`: Practice scripts for PyAutoGUI automation.

More automation examples will be added soon.
